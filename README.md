# JarvisAI 🤖

A Python-based voice assistant inspired by J.A.R.V.I.S.  
It listens to voice commands, responds using AI, and performs basic automation tasks like opening websites.

## 🚀 Features
- Speech Recognition
- Text-to-Speech
- OpenAI-powered responses
- Basic task automation

## 🛠 Tech Stack
Python, speech_recognition, Web Browser, OpenAI API
